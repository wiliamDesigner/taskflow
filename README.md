# 🚀 TaskFlow

Aplicação Full Stack para gerenciamento de tarefas, desenvolvida para praticar e demonstrar conhecimentos em desenvolvimento web.

## 💻 Tecnologias utilizadas

**Frontend**
- React
- Vite
- Axios

**Backend**
- Node.js
- Express
- PostgreSQL
- JWT
- bcryptjs

## ✨ Funcionalidades

- Cadastro de usuários
- Login e autenticação
- Criação de tarefas
- Edição de tarefas
- Exclusão de tarefas
- Marcar tarefas como concluídas

## ⚙️ Como executar localmente

### 1. Clone o repositório

```bash
git clone https://github.com/williamDesigner/taskflow.git
```

### 2. Backend

```bash
cd taskflow/backend
npm install
npm start
```

Configure as variáveis de ambiente no arquivo `.env`:

```env
DATABASE_URL=sua_url_do_postgresql
JWT_SECRET=sua_chave_secreta
```

### 3. Frontend

Em outro terminal:

```bash
cd taskflow/frontend
npm install
npm run dev
```

## 🎯 Objetivo

Projeto desenvolvido com o objetivo de aprimorar habilidades em desenvolvimento Full Stack, integração entre frontend e backend, autenticação de usuários e banco de dados.
